AiiDA workflows for mechanical properties

Research software · AiiDA · Quantum ESPRESSO · ASE · Python

This work explores how to automate families of first-principles calculations for mechanical properties. AiiDA coordinates the calculations, Quantum ESPRESSO supplies the SCF energies, and Python tools collect and fit the results.

Equation-of-state workflow

The equation-of-state workflow organises an energy–volume scan to estimate the equilibrium energy, equilibrium volume and bulk modulus. It combines structure rescaling through ASE with Quantum ESPRESSO calculations managed by an AiiDA WorkChain.

  1. Start from a reference structure. Choose the structure and the calculation settings to use throughout the scan.
  2. Generate a family of cells. Scale the lattice while preserving fractional atomic coordinates, and record each resulting cell volume.
  3. Submit the SCF calculations. Use AiiDA to launch the related Quantum ESPRESSO jobs and retain their calculation records.
  4. Collect volumes and energies. Gather the outputs into an energy–volume dataset with its energy units.
  5. Fit the equation of state. Analyse the dataset with ASE and Birch–Murnaghan fitting routines to estimate the equilibrium properties.

This section describes the workflow design. A standalone tutorial and reference dataset are still to be prepared.

Elastic-constant workflow prototype

The public elastic repository explores a related idea: apply small strains, calculate the resulting energies and fit the elastic response. The code targets the C₃₃ elastic component.

Early prototype · Strain application and fitting need correction and validation

The current implementation needs the requested strain values to be passed through to the deformation and the energy collection and fit to be corrected before it can produce a reliable elastic constant. The source is useful for studying the workflow structure; a validated calculation example is still needed.

Reading the public source

Main files in the elastic workflow repository.
FileRole in the prototype
deform.pyDefines a strain matrix and applies a deformation to an ASE cell before returning an AiiDA structure.
common_wf.pyContains the Quantum ESPRESSO builder helper and equation-of-state fitting utilities. Its fitting helper credits the Delta Project code.
elastic_fit.pyDefines the AiiDA WorkChain for submitting calculations and collecting results, with an intended C₃₃ fitting stage.
sub.pyShows an example submission with calculation settings and scheduler resources that need adapting to the user's AiiDA environment.

Start with the deformation routine, then follow the SCF builder, the WorkChain and the submission example. The scripts use AiiDA, aiida-quantumespresso, ASE, NumPy and SciPy; the repository does not yet specify a tested installation environment.
